#
#   path <TAB> symbol <TAB> construct[#n] <TAB> reason <TAB> owner <TAB> card <TAB> expires
#
# The key is path + symbol + construct: the enclosing declaration (function/method name, `init`, or a
# package-scope name) and the construct kind, with #2, #3... when one symbol carries several constructs of
# the same kind. The line is NOT part of the key, so an edit above a construct does not invalidate the

# key, an empty reason/owner/card or a bad `expires` is a format error in every phase. The entry count may
