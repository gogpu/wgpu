# Public-layer waiver file. Reviewed exemptions from the construct ban of the public-layer rule
# (internal/layoutcheck/astcheck.go). One data row per exempt construct, tab-separated:
#
#   path <TAB> symbol <TAB> construct[#n] <TAB> reason <TAB> owner <TAB> card <TAB> expires
#
# The key is path + symbol + construct: the enclosing declaration and the construct kind, with #2, #3... when
# one symbol carries several constructs of the same kind. The symbol is receiver-qualified for a method —
# (*T).M for a pointer receiver, (T).M for a value one — and the bare name for a package-level function and
# for init; descriptor.go declares eighteen toHAL methods, so a bare method name would let one type's waiver
# exempt another's construct. The line is NOT part of the key, so an edit above a construct does not
# invalidate the review and a different construct on the old line is not exempted; the checker prints the live
# file:line as evidence.
#
# An entry whose key matches no finding is a failure in every phase (a stale or unused waiver). A duplicate
# key, an empty reason/owner/card or a bad `expires` is a format error in every phase. The entry count may
# not exceed `limit:`, and the list grows only through a dated amendment (the CI audit forbids growth against
# the PR base, and against the previous head on a push to main). `expires` is `YYYY-MM-DD` or `permanent`;
# the format is checked here, the clock in tools/waiveraudit (a date-based unit failure would red the tree
# overnight with no push behind it).
#
# Every `permanent` row names its removal path, because `permanent` alone would make the time bound bite
# nothing: the conversions are removed by P2-API-034/P2-API-035 before v1.0 and re-reviewed at each release,
# the wgputest facade rows by P2-API-032 before v1.0, and the factory rows are design (ADR-070 §15.13) with
# no removal planned.
#
# Groups: six wgputest facade rows (P2-API-032); 31 boundary conversions, carded for the generated-projection
# route (P2-API-034) or the internal-mirror route (P2-API-035). Twenty-five of those rows cannot move into
# internal because internal cannot import root (R5). The other six rows belong to four D7 thin-sweep boundary
# declarations that do not take root types, so R5 is not their reason (two of them carry two loops each):
# surface_native.go createHALSurfaces, device_browser.go stencilOpToJS and the two convertVertexBufferLayouts.
# Four factory closures are design, not debt (ADR-070 §15.13).
